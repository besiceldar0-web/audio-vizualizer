# Audio Vizualizer - Interaktivni Muzički Plejer

Završni projekat iz Web programiranja - interaktivni muzički plejer sa vizualizacijom zvuka u realnom vremenu.

## Funkcionalnosti

- Upload audio fajla (MP3/WAV)
- Reprodukcija muzike (Play, Pause, Stop)
- Vizualizacija frekvencija u realnom vremenu (Canvas + AnalyserNode)
- Talasni oblik (waveform)
- Plejlista sa dodavanjem pesama
- Next/Prev dugmad za navigaciju
- Progress bar sa prikazom vremena
- Kontrola volumena
- Toggle vizualizacije
- Validacija formata fajla
- Responzivan dizajn sa tamnom temom i neonskim efektima

## Korištene tehnologije

- HTML5 (Audio element, Canvas)
- CSS3 (Grid, Flexbox, Animacije, Neonski efekti)
- JavaScript (AudioContext API, AnalyserNode, requestAnimationFrame)

## Pokretanje

1. Kloniraj repozitorijum
2. Dodaj MP3/WAV fajlove u `/demo/` folder (opciono)
3. Otvori `index.html` kroz Live Server ili XAMPP

Ili otvori live demo: https://besiceldar0-web.github.io/audio-vizualizer/
